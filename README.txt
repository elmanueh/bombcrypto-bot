1. Descomprimir el archivo WinRar, hazlo donde quieras, no importa el lugar.


2. Accede dentro de la carpeta y configura el archivo " config.yaml " dependiendo de tus personajes.


3. Para que el BOT funcione, necesita hacer uso de librerias y codigo PYTHON.
   Comenzando con Python, debe instalarlo en su ordenador desde el siguiente enlace.
   Para instalarlas, abre un terminal(CMD), accede hasta la carpeta del bot, y escribe el comando " pip install -r requeriments.txt ".


4. El bot ya esta preparado para funcionar.
   Para ejecutarlo, debes continuar con el terminal(CMD) abierto y dentro de la carpeta del juego, si estas ahí, escribe el comando " py index.py".
